# Implementation plans

Each plan implements one proposal that was accepted in the chat. A plan is written
only after the proposal is accepted, after every question round is closed, and
after every decision that required a human has its ADR.

Plans are numbered sequentially and zero-padded to four digits. A plan records
what was intended; it is not rewritten after the fact to match what happened. If
reality contradicts a plan during implementation, the agent stops and asks.

Create the next plan with `/surf:new-plan`.
